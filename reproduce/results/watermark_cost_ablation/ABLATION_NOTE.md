# DirBucket — Watermark Cost / Strength Ablation

## Setup

- **Source docs**: 54 documents sampled from the FARAD manifest (stratified by provider)
- **Sentences**: 1308 total sentences analysed
- **Candidate generation**: K=24 candidates per round, ρ=6 rounds (paper setting), one run
- **Simulation**: all 9 (K, ρ) combinations derived from the same saved candidates
- **Detection Z anchor**: 11.85 (from sensitivity sweep: W=28, τ_sim=0.82, T_min=25, 18 target-seed pairs)
- **Cost note**: K candidates are generated in a SINGLE API call per round (batch prompt). Changing K does NOT change the number of API calls; only ρ (the number of rounds) determines the call count.
